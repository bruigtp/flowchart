# update_y_stack_unite

Function to update the vertical position of the previuosly created
flowcharts, to stack the two flowcharts with fc_stack(), when `unite` is
TRUE.

## Usage

``` r
update_y_stack_unite(y, x, type)
```

## Arguments

- y:

  old vertical position of the boxes

- x:

  old horizontal position of the boxes

- type:

  type of the boxes
