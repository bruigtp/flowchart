# plot.fc

plot method for `fc` object. It is a wrapper for the
[fc_draw](https://bruigtp.github.io/flowchart/reference/fc_draw.md)
function.

## Usage

``` r
# S3 method for class 'fc'
plot(x, ...)
```

## Arguments

- x:

  A `fc` object created using flowchart functions

- ...:

  Arguments passed to
  [fc_draw](https://bruigtp.github.io/flowchart/reference/fc_draw.md).
